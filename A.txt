Iterative workflow — ittrative_workflow.ipynb

Purpose
- Demonstrates an iterative generate → evaluate → optimize loop for creating and improving LinkedIn posts using LangGraph state graphs and LLM prompts.

State shape (LinkedinState)
- topic: str
- post: str
- evaluation: str (label)
- feedback: str (detailed evaluator feedback)
- iteration: int
- max_iteration: int

Example initial_state
{
  "topic": "Why learning LangGraph changed how I build AI applications",
  "post": "",
  "evaluation": "",
  "iteration": 0,
  "max_iteration": 3
}

State nodes (functions)
- generate_post(state)
  - Role: creative content generator (e.g., "You are a funny and clever LinkedIn influencer.")
  - Produces a draft post and writes to state['post'].

- evaluate_post(state)
  - Role: strict evaluator/editor.
  - Returns an evaluation label (e.g., "need_improvement" or "good") and detailed feedback in state['evaluation']/state['feedback'].

- optimize_post(state)
  - Role: LinkedIn content strategist/editor.
  - Uses evaluator feedback to rewrite and improve the post; updates state['post'].

Routing and control
- route_evaluation(state): maps evaluation labels to the next node
  - "need_improvement" -> optimize_post
  - otherwise -> END
- Graph edges and flow
  - START -> generate_post -> evaluate_post
  - evaluate_post -> (route) optimize_post or END
  - optimize_post -> evaluate_post (loop)
- Iteration control: increment state['iteration'] each loop; stop when evaluation acceptable or iteration >= max_iteration.

Execution
- Build a StateGraph(LinkedinState), add nodes & edges, compile and invoke with initial_state.
- Example invocation: result = workflow.invoke(initial_state)
- Final result contains final post, evaluation label, feedback, and iteration count.

Prompts & behavior notes
- Distinct LLM roles separate creative generation, critical evaluation, and editorial optimization.
- Evaluation labels are used programmatically to decide routing and looping.
- Example notebook run shows the loop ending when max_iteration reached or evaluation is satisfactory.
